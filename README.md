# 🌱 TaskMate

A simple task management app built with **HTML, CSS, and JavaScript**.

TaskMate is a small DOM-based project focused on practicing JavaScript by building something actually useful.

## ✨ Features

* ➕ Add tasks
* ✅ Mark tasks as completed
* 🏷️ Assign priority badges (Low / Medium / High)
* 📅 Add and view tasks by date
* 🌱 Simple progress/tree growth based on completed tasks
* 💾 Save tasks using Local Storage
* 🔔 Basic reminders (optional)

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript
* DOM Manipulation
* Local Storage

## 🎯 Project Goal

The goal of TaskMate is to build a **simple and functional task manager** while practicing core JavaScript and DOM concepts.

This is intentionally kept small and focused rather than being a full-scale productivity application.
